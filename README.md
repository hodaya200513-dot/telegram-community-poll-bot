# 📊 Telegram Community Poll Bot

מערכת חכמה לניהול סקרים אינטראקטיביים בקהילות טלגרם. הפרויקט משלב בוט טלגרם נוח למשתמשים יחד עם ממשק ניהול שולחני (GUI) למנהל הקהילה.

🔗 **לינק לבוט בטלגרם:** [t.me/HodayaAchvaBot](https://t.me/HodayaAchvaBot)  
💬 **שם משתמש לחיפוש בטלגרם:** `@HodayaAchvaBot`

## ✨ תכונות מרכזיות
* **הצטרפות לקהילה:** משתמשים נרשמים לקהילה דרך הבוט ונוספים מיד למסד הנתונים של הקהילה.
* **יצירת סקרים חכמה:** פאנל הניהול מאפשר כתיבת שאלות ותשובות בצורה ידנית, או יצירת שאלות אוטומטית על בסיס נושא בעזרת אינטגרציה ל-ChatGPT.
* **אינטראקציה חלקה:** הסקרים נשלחים למשתתפים כהודעות עם כפתורי Inline. הלחיצות מעדכנות את ההודעה עצמה כדי לשמור על היסטוריית צ'אט נקייה.
* **ניהול זמן אוטומטי:** כל סקר קצוב ל-5 דקות בדיוק, עם מערכת תזכורות אוטומטית הנשלחת למי שטרם סיים לענות לאחר 3 דקות.
* **תצוגה בזמן אמת:** ממשק Java Swing מודרני מציג למנהל את התקדמות המענה בזמן אמת, ובסיום הסקר מציג פאנל תוצאות סטטיסטי מפורט.

## 🛠️ טכנולוגיות
* **שפת תכנות:** Java
* **ממשק משתמש (GUI):** Java Swing (עיצוב מודרני עם תמיכה ב-RTL)
* **API טלגרם:** `TelegramBots` library
* **בינה מלאכותית:** OpenAI API (ChatGPT) ליצירת שאלות דינמיות

## 🚀 איך להריץ את הפרויקט?
1. הורידו את הפרויקט (Clone).
2. פתחו את הפרויקט בסביבת הפיתוח (IntelliJ / Eclipse).
3. ודאו שהזנתם את מפתחות ה-API שלכם בקוד:
   * **Telegram Bot Token:** (מתקבל מ-BotFather)
   * **OpenAI API Key:** (מתקבל מ-OpenAI)
4. הריצו את הפרויקט.
5. חלון הניהול ייפתח - כעת ניתן לחפש את הבוט בטלגרם (`@HodayaAchvaBot`), לשלוח `/start` ולהתחיל ליצור סקרים!
